# Personal Library Management System

## Description

The Personal Library Management System is a simple ASP.NET Web Forms application developed as a learning project. It helps users maintain a digital record of books, manage borrowing activities, and keep track of available and borrowed books. The project demonstrates basic CRUD operations, user authentication, and SQL Server database connectivity.

---

## Functionality

- User registration and login
- Add, update, and delete books
- View all available books
- Borrow and return books
- View borrowed and overdue books
- Logout and session management
